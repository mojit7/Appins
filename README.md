# فروشگاه‌یار — دستیار فروشگاه اینستاگرام (Appins)

سامانه‌ی تک‌فروشگاهی برای مدیریت حساب حرفه‌ای اینستاگرام از طریق داشبورد فارسی (RTL) و ربات تلگرام.

## قابلیت‌ها (نقشه راه ۱۰ مرحله‌ای)
- مدیریت محصولات
- کپشن‌نویسی با کمک هوش مصنوعی
- پیش‌نویس محتوا و زمان‌بندی انتشار (در حدی که API رسمی متا پشتیبانی کند)
- بینش‌های حساب (Insights)
- گردش‌کارهای ربات تلگرام
- پایش رقبا: پیاده‌سازی نمی‌شود.

## معماری
توضیحات کامل در `docs/ARCHITECTURE.md` و چک‌لیست اجرا در `docs/IMPLEMENTATION_CHECKLIST.md`.

## اجرا
```bash
npm install
cp .env.example .env   # مقادیر واقعی را وارد کنید
npm run dev            # پایانگاه API
npm run dev --workspace web   # داشبورد
npm test
```

## اصول مهندسی
- تمام اعتبارنامه‌ها و عملیات ممتاز فقط سمت سرور نگه‌داری می‌شوند.
- هیچ قابلیت API، اتصال موفق، متریک یا انتشارِ ساخته‌شده‌ای جعل نمی‌شود.
- رابط کاربری فارسی‌اول با چیدمان RTL است.
