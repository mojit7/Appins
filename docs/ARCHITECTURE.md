# یادداشت‌های معماری

## تصمیم‌ها
1. **Runtime**: Node.js 20 + TypeScript strict. پایانگاه API با Fastify (خطاهای متمرکز، تزریق وابستگی، تست‌پذیری با `app.inject`).
2. **جدا‌سازی لایه‌ها**: `server` (HTTP) — `domain` (منطق کسب‌وکار و اسکیماها) — `data` (مخازن، مرز دسترسی) — `db` (اتصال/مهاجرت) — `integrations` (اینستاگرام/تلگرام/AI) — `jobs` (کارهای پس‌زمینه). UI وب در `web` (Vite + React، فارسی RTL).
3. **اعتبارسنجی**: zod به‌عنوان مرجع تک‌حقیقتِ شکل داده‌ها (env، دامنه، درخواست‌ها).
4. **خطاها**: سلسله‌مراتب `AppError` + `setErrorHandler` متمرکز؛ پاسخ خطا فارسی و بدون نشت جزئیات داخلی.
5. **پیکربندی**: فقط از طریق متغیرهای محیطی با اعتبارسنجی هنگام راه‌اندازی.
6. **امنیت**: همه توکن‌ها سمت سرور؛ مرورگر هرگز به متا/تلگرام مستقیم دسترسی ندارد؛ نشست با `SESSION_SECRET` ≥ ۳۲ نویسه.

## ماندگاری داده (مرحله ۳)
- **موتور**: PostgreSQL >= 13 (نیازمندی: `gen_random_uuid()` داخلی). دسترسی با `pg` رسمی (node-postgres) و پرس‌وجوهای کاملاً پارامتری برای پیشگیری از تزریق SQL.
- **مهاجرت**: اجراکننده سبک داخلی با جدول `schema_migrations`؛ هر مهاجرت در تراکنش مجزا و بازتولیدپذیر (idempotent در اجرای مجدد).
- **موجودیت‌ها از نیازمندی واقعی**: `products`، `content_drafts`، `publishing_jobs`، `integration_connections` (فقط فراداده؛ بدون توکن/رمز)، `operational_logs` (فقط-افزودنی).
- **یکتی/قیود**: sku یکتا؛ قید CHECK روی وضعیت‌ها و مقادیر؛ `ON DELETE RESTRICT` برای جلوگیری از رکورد یتیم (حذف محصولِ دارای پیش‌نویس مسدود است).
- **تراکنش**: هر مهاجرت و هر عملیات چندمرحله‌ای در تراکنش (`withTransaction`).
- **صفحه‌بندی**: همه فهرست‌ها با page/pageSize (سقف ۱۰۰).
- **مرز دسترسی**: همه مخازن با `assertActor(ctx)` شروع می‌شوند؛ عملیات بدون زمینه کاربرِ مالک ۴۰۳ می‌گیرد. نقش‌ها فعلاً تک‌مالکی است.

## ادغام‌های بیرونی (فقط بر پایه مستندات رسمی)
- **اینستاگرام/متا**: جریان رسمی برای حساب‌های Professional. بلاکر ثبت‌شده: «Instagram Login» مستقیم برای همه سرصفحه‌ها پشتیبانی نمی‌شود؛ لایه `integrations/instagram` عایق‌بندی Interface-محور است. تا مرحله ۴ هیچ ادعای اتصال نداریم.
- **تلگرام**: Bot API رسمی (مرحله ۷؛ توکن فقط سمت سرور).
- **هوش مصنوعی**: صرفاً تولید کپشن فارسی (مرحله ۶).

## نکات
- رقبا پایش نمی‌شوند (خواسته صریح محصول).
- زمان‌بندی انتشار فقط در حدی که API رسمی متا اجازه دهد.
